# 本地音视频转字幕 MVP v0.1（Windows x64）

这是一个面向普通 Windows 用户的 whisper.cpp 图形界面。把音频或视频拖入窗口，选择语言、模型和输出格式，即可在本机生成 SRT、TXT 或 VTT 文件，不需要输入命令。

本项目不是 whisper.cpp 或 OpenAI 的官方产品。v0.1 只使用 CPU，不包含未经测试的 NVIDIA、Vulkan 或其他显卡加速选项。

## 主要功能

- 支持拖入或选择常见音视频文件，先由 FFmpeg 转换为 16 kHz 单声道音频。
- 支持自动识别、中文、英文、日文、韩文和粤语。
- 提供 Base、Small、Medium 三档多语言模型，模型按需下载。
- 可同时生成 SRT、TXT 和 VTT；默认生成 SRT 与 TXT。
- 中文等无空格语言的 SRT 由程序按标点和语义边界切分，避免从词语中间截断；英文使用 whisper.cpp 按单词切分。
- 默认保存到原文件目录，也可以指定其他文件夹。
- 已有同名结果时自动使用 `文件名 (2)`，不会覆盖原字幕。
- 显示模型下载进度、识别进度和运行记录，任务可以取消。
- 音视频和识别结果只在本机处理，不上传到服务器。

## 系统要求

- Windows 10 或 Windows 11，64 位。
- 不要求独立显卡。
- 建议至少保留 3 GiB 可用磁盘空间，以便安装 FFmpeg、运行库和模型。
- 模型越大，通常需要更多内存和处理时间。

Windows 7 不在当前支持范围内。Windows 8/8.1 尚未验证。

## 第一次使用

1. 完整解压 Release 中的 ZIP，不要直接在压缩包里运行。
2. 双击 `local-subtitle-gui.exe`。
3. 点击“检查运行组件”，或在第一次生成字幕时确认安装。
4. 程序从项目列出的官方地址下载 whisper.cpp CPU运行库和 FFmpeg，并在安装前校验文件。
5. 选择模型后，程序只下载这一个模型；其他模型不会同时下载。

轻量 Release 不包含 whisper.cpp、FFmpeg 或模型二进制，也不会修改系统 PATH。组件和模型保存在程序目录，因此请把整个文件夹放在当前账户可以写入的位置。

## 模型选择

| 界面选项 | 模型文件 | 官方标注大小 | 建议用途 |
| --- | --- | ---: | --- |
| 快速 | `ggml-base.bin` | 约 142 MiB | 快速预览、普通配置电脑 |
| 均衡（默认） | `ggml-small.bin` | 约 466 MiB | 日常中文和英文内容 |
| 高质量 | `ggml-medium.bin` | 约 1.5 GiB | 更重视准确率、可以接受较长等待 |

所有模型均为多语言版本，不使用名称中带 `.en` 的纯英文模型。模型来源、官方哈希和许可证说明见 `THIRD_PARTY_NOTICES.md`。

## 生成字幕

1. 将一个音频或视频文件拖入窗口，也可以点击“选择文件”。
2. 选择识别语言。语言不确定时使用“自动识别”。
3. 选择识别模型和 CPU线程数。
4. 勾选 SRT、TXT 或 VTT，至少选择一种。
5. 选择保存位置，点击“开始生成字幕”。

程序先用 FFmpeg 提取音轨，再调用 whisper.cpp。v0.1 会显式传入 `--no-gpu`，确保只使用经过测试的 CPU 路径。英文使用 `--max-len 28 --split-on-word`；中文、日文、韩文和粤语不做硬字符切分，SRT 在识别完成后由程序按标点重新排版。

输出文件沿用原文件名。例如：

```text
采访视频.mp4
采访视频.srt
采访视频.txt
```

如果目标目录已经存在 `采访视频.srt`，新结果会保存为 `采访视频 (2).srt`，不会覆盖旧文件。

## 准确率说明

本地识别结果需要人工校对。准确率会受到录音质量、口音、多人重叠说话、背景音乐、专有名词和模型大小影响。程序不会承诺百分之百准确，也不会自动判断内容事实是否正确。

“中文”表示要求 Whisper 以中文进行转写，不额外执行简繁转换。输出使用简体还是繁体可能受音频内容和模型结果影响。

## 隐私

- 音视频不会上传到本项目的服务器；本项目也不提供服务器。
- 首次安装组件和模型时需要联网，下载结束后可以离线识别。
- 临时 WAV 文件位于程序目录的 `.runtime-temp`，任务正常结束或取消后会尝试删除。
- 模型保存在 `models` 文件夹，可以通过界面的“打开模型目录”查看。

## 已知限制

- v0.1 一次只处理一个文件，没有批量队列。
- 没有字幕时间轴编辑器、翻译、说话人区分和实时麦克风转写。
- 没有 NVIDIA、Vulkan、OpenVINO 等加速选项。
- Medium 模型体积较大，在普通 CPU 上可能明显较慢。
- 取消任务时会结束 FFmpeg 或 whisper.cpp；异常关机可能留下 `.runtime-temp` 文件夹，可在程序未运行时手动删除。
- 程序没有代码签名，Windows 第一次运行可能显示 SmartScreen 提示。请从项目自己的 Release 下载并核对 SHA-256。

## 构建与测试

源码使用 Windows 自带的 .NET Framework C# 编译器，不需要安装 .NET SDK：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

构建脚本会生成 `local-subtitle-gui.exe`，并运行参数、模型映射、哈希、ZIP提取、防覆盖命名和界面测试。常规测试不会下载模型或大型组件。

开发阶段已经使用 whisper.cpp 官方 Windows CPU运行库、Base 多语言模型和官方 JFK 示例音频完成端到端测试，实际生成 SRT 与 TXT；运行日志确认 `use gpu = 0`。
